# 📖 Overview

Spam emails continue to be one of the biggest challenges in digital communication. Traditional keyword filtering is no longer sufficient because modern spam continuously changes its wording and structure.

This project demonstrates how **Deep Learning** can automatically learn hidden patterns from email text to distinguish legitimate emails from spam without relying on manually written rules.

Instead of searching for predefined keywords, the model learns semantic relationships between words using TensorFlow and predicts whether an incoming message is spam or legitimate.

This project covers the complete machine learning workflow:

- Data preprocessing
- Text cleaning
- Tokenization
- Vectorization
- Model training
- Validation
- Performance evaluation
- Prediction on unseen emails

# 🏗 Model Architecture

The classifier is built using TensorFlow/Keras.

Typical workflow:

```
Input Email

↓

Text Preprocessing

↓

Text Vectorization

↓

Embedding / Dense Layers

↓

Hidden Neural Layers

↓

Sigmoid Output Layer

↓

Spam Probability
```

The output layer predicts a probability between **0 and 1**.

Example:

| Probability | Prediction |
|-------------|------------|
| 0.96 | Spam |
| 0.91 | Spam |
| 0.12 | Ham |
| 0.03 | Ham |

# 📊 Dataset

The model was trained using a labeled spam email dataset containing two classes:

| Class | Description |
|--------|-------------|
| Spam | Promotional, fraudulent or unwanted emails |
| Ham | Legitimate and genuine emails |

Dataset preprocessing included:

- Removing unnecessary symbols
- Lowercase normalization
- Tokenization
- Vocabulary creation
- Label encoding
- Sequence padding

These preprocessing steps improve model consistency and training performance.

# ⚙ Installation

## 1. Clone the Repository

```bash
git clone https://github.com/Shahrukh-aidev/Detecting-Spam-Emails-using-tensorflow-in-python.git

cd Detecting-Spam-Emails-using-tensorflow-in-python
```

---

## 2. Create a Virtual Environment (Recommended)

### Windows

```bash
python -m venv venv

venv\Scripts\activate
```

```bash
python3 -m venv venv
```

- Train the neural network
- Evaluate the model
- Predict whether an email is Spam or Ham
